# Creator notes

This directory holds long-form design musing — shower thoughts,
thematic explorations, process notes — that is too exploratory to
live in `DESIGN.md` but should still be preserved for future design
sessions, human or AI.

**Contains thematic spoilers.** These are creator-facing notes, not
player-facing content. Anyone who interacts with the game by running
it will not see any of this; anyone browsing the repo source will.
That is the intended audience: future contributors and future design
sessions, not players looking for a blind experience.

Files here are dated or numbered so they can accumulate without
conflict. Decisions that are actually in scope for the project should
graduate into `DESIGN.md` or a plan document; this directory is for
things still percolating.
